How the history works

Collection runs on the AI server every 15 seconds, including when this page is closed. A live minute bar grows as measurements arrive. Every minute’s recorded averages and peaks are retained indefinitely, alongside hourly and daily summaries. Large ranges automatically use a coarser interval; zoom in for minute detail.

Recording starts at installation. There is no invented data for earlier years or for downtime. CPU is based on process time; RAM uses proportional set size where permitted. GPU engine counters are used when exposed by the driver. Protected processes, kernel use and unmeasurable activity remain unattributed. Short-lived processes between samples may be missed. New apps are discovered from processes; generic workers inherit recognized parent app names.

All history stays on Ubuntu. This page has read-only access over the authenticated dashboard connection. Cost preferences are saved only in this browser and recalculate the selected history; they are not historical electricity bills. “Forever” means no automatic deletion; daily snapshots keep two backup copies on the same disk. Copy backups elsewhere for protection against disk failure.
